From his first snap, the model adds his games one play at a time, and you can watch them take over.

sim = {

  const limits = (par, v, k = cfg.k) => ({ A: k * Math.max(par.A5 + cfg.slope.a * (v - 5), 0),
    B: k * Math.max(par.B4 + cfg.slope.b * (v - 4), 0.1), L: k * Math.max(par.L4 + cfg.slope.l * (v - 4), 0.1) });
  // the 720 strategies after T s (player frame: x forward, y left); trace keeps every step and push
  const simulate = (par, v0, T, k = cfg.k, trace = false) => {
    const dt = cfg.dt, top = k * par.top, n = nd * nb * 2, steps = Math.round(T / dt);
    const phi = d3.range(n).map(i => -Math.PI + 2 * Math.PI * ((i % nd) + 1) / nd);
    const q = d3.range(n).map(i => cfg.brake_share[Math.floor(i / nd) % nb]);
    const vs = d3.range(n).map(i => i < nd * nb ? Infinity : 0);
    const x = new Float64Array(n), y = new Float64Array(n), h = new Float64Array(n), v = new Float64Array(n).fill(Math.min(v0, top));
    const path = trace ? d3.range(n).map(() => [[0, 0]]) : null, push = trace ? d3.range(n).map(() => []) : null;
    for (let s = 1; s <= steps; s++) for (let i = 0; i < n; i++) {
      const { A, B, L } = limits(par, v[i], k);
      let e = Math.atan2(Math.sin(phi[i] - h[i]), Math.cos(phi[i] - h[i]));
      if (v[i] < 0.5) { h[i] = phi[i]; e = 0; }
      const pivot = Math.abs(e) > cfg.pivot && q[i] > 0;
      const an = Math.sign(e) * Math.min(pivot ? L * Math.sqrt(1 - q[i] * q[i]) : L, v[i] * Math.abs(e) / dt);
      const frac = Math.sqrt(Math.max(0, 1 - (an / L) ** 2));
      let at = pivot ? -q[i] * B : (v[i] > vs[i] ? -B * frac : A * frac);
      if (v[i] >= top && at > 0) at = 0;
      if (trace) push[i].push({ an, at, v: v[i], A, B, L, pivot });
      h[i] += (v[i] > 0 ? an / Math.max(v[i], 1e-6) : 0) * dt;
      v[i] = Math.min(Math.max(v[i] + at * dt, 0), top);
      x[i] += v[i] * Math.cos(h[i]) * dt; y[i] += v[i] * Math.sin(h[i]) * dt;
      if (trace) path[i].push([x[i], y[i]]);
    }
    return { x: Array.from(x), y: Array.from(y), path, push };
  };
  const hull = (x, y) => d3.polygonHull(x.map((v, i) => [v, y[i]])) || [];
  const area = h => h.length > 2 ? Math.abs(d3.polygonArea(h)) : 0;
  // strategy index for a target direction (rad, left +), brake-share variant and flat out / stop
  const index = (ang, qi, stop) => (stop ? nd * nb : 0) + qi * nd + Math.round((ang + Math.PI) / (2 * Math.PI) * nd) - 1;
  return { cfg, limits, simulate, hull, area, index };
}

From limits to an envelope. Four limits are not yet a movement. To turn them into where he can get to, the model treats him as a single point with a fixed budget of grip. At 4 yd/s his predicted limits let him speed up at – yd/s², brake at – or turn at – (acceleration sideways). Mixing them draws on the same budget, so every push he can make lies inside this oval: speeding up at the top, braking at the bottom, turning to either side. This is the friction ellipse from vehicle dynamics (Pacejka 2012). The simulator was written for this project; the idea of playing a player’s motion limits forward to find where he can get to goes back to “dominant region” models in soccer (Taki & Hasegawa 2000; Fujimura & Sugihara 2005). Anzer & Bauer (2022) used envelopes like these, built from where players actually got to, to work out which player could reach a pass first.

The budget depends on how fast he is going. The faster a lineman moves, the less he has left to speed up with and the less he can brake, but the more sideways grip he has for turning. Those slopes are shared by every DL and come from game data; only the level is his. Speed is capped at his top speed, – yd/s.

Notes and limitations

  • The 2025 combine. Its tracking reads acceleration lower than earlier years for the same official times, and within role it barely ranks the class. The model removes a per-year offset, but it can’t add a ranking that isn’t there.
  • Preseason counts. A rookie’s first tracked games are usually preseason, often against backups.
  • Thirty-play rule. Before 30 plays the model ignores his games entirely, which is why the update jumps when it first switches on.
  • Only sample players are tracked. About 21 of a rookie’s plays a game are tracked, not every snap.
  • The simulator is a point mass with one calibration factor for everyone. It knows nothing about blockers.
  • 43 rookies is one class. The error curves are descriptive; rows from the same player aren’t independent.

What it could be used for

The envelope answers one question for one player: where can he be, and how soon? Many spatial models in football need that answer for every player on the field, and most of them give everyone the same limits. With every player tracked, these envelopes could feed them.

  • Contested space. The Contested Space Diagrams (Velankar, Big Data Bowl 2026 finalist) score each spot by how much sooner the ball carrier can get there than each defender, from a time-to-reach model with one set of limits taken from the literature. Each player’s nested envelopes give his own time to reach every spot, so the diagram becomes his rather than an average player’s, and for a rookie it works from his first snap through the combine prior. That paper names run-game gaps and the pocket as next steps, which is where defensive linemen play.
  • Where he could have gone. The Decision Point (2026 finalist) draws the region a defensive back can reach before the ball arrives, using average DB ability, and lists player-specific speed, acceleration and change of direction as future work. That region is an envelope, and the same pipeline runs for any position with a combine.
  • Fair ghosts. Ghostbusters (2026 grand prize) and NFL Ghosts (Yurko, Nguyen & Pelechrinis) judge a defender against where other players would have been. The envelope can drop ghost positions this player could not physically have reached, so he is judged only on choices he had.
  • The pocket. With the quarterback and all five blockers tracked, each rusher’s envelope against the quarterback’s escape envelope says how soon pressure was possible, not just when it arrived. That adds a physical limit to pass-rush measures such as STRAIN (Nguyen, Yurko & Matthews 2023) and the 2023 winner’s pocket-pressure maps (Inayatali, White & Hocevar).
  • Blocker against rusher. Offensive linemen have combines too. Setting a tackle’s sideways envelope against an edge rusher’s turns “can he mirror him?” into a question of physical limits.
  • Run fits and recovery. Which gaps each lineman can fill before the ball carrier gets there, and how much an upfield rush costs on screens and draws. The 6 yd/s envelope already shows the trade: the faster he goes, the less he can come back.
  • Scouting and in-season tracking. The snap-1 envelope is a draft-day projection from the combine. The game-by-game update is a running read of how each player moves, so a drop over a few games could be worth a look for fatigue or injury (not tested here).

Full tracking would also help the model itself. Every snap tracked, rather than about 21 plays a game, means a rookie’s games outweigh his combine within his first game or two instead of around game –.

      .attr("opacity", j => dotMode === "off" ? 0 : dotMode === "field" ? ((name === "field40" && has40 && !is40(j)) ? 0 : 0.85) : (fr.a[j] != null ? 0.45 : 0));
    if (name === "phys3") drawPhys3(Math.min(S2, Math.floor(prog * (S2 + 1))));
    if (name === "phys5") drawPhys5(Math.min(S2, Math.floor(prog * (S2 + 1))));
    if (name === "blend") drawBlend(prog);
    // calibration k scrub
    if (name.startsWith("calib")) {
      const H6 = pop.calibration.hulls;
      const i = name === "calib1" ? 0 : name === "calib3" ? H6.findIndex(h => Math.abs(h.k - pop.k) < 1e-6) : Math.min(H6.length - 1, Math.floor(prog * H6.length));
      const h = H6[i]; calHull.transition().duration(dur).attr("d", hullPath(h));
      calLab.text(`k = ${h.k.toFixed(2)}: ${Math.round(h.inside * 100)}% of his moves inside`);
      kDot.attr("cx", kx(Math.min(1.6, h.k))).attr("cy", ky(covAt(h.k)));
    }
    // play by play
    if (name === "pbp" || name === "pbpEnd") {
      const N = P.pbp.length, i = name === "pbpEnd" ? N - 1 : Math.min(N - 1, Math.floor(prog * N));
      const s = P.pbp[i];
      pbpPaths.attr("opacity", (d, k) => k > i ? 0 : k === i ? 1 : 0.18).attr("stroke-width", (d, k) => k === i ? 2.6 : 1);
      gDots.attr("opacity", d => d[0] <= i ? 0.55 : 0);
      playLab.text(`Play ${i + 1} · game ${s.play.game} (${glab(s.play.game)})${s.play.align ? " · lined up " + (s.play.align === "EDGE" ? "on the edge" : s.play.align === "INTERIOR_LINE" ? "inside" : s.play.align.toLowerCase()) : ""}`);
      const r = a5(s), y5 = v => qy(v);
      tPrior.attr("y1", y5(r.prior)).attr("y2", y5(r.prior)).attr("opacity", 1);
      tGames.attr("y1", y5(r.games ?? 0)).attr("y2", y5(r.games ?? 0)).attr("opacity", r.games != null ? 1 : 0);
      tUpd.attr("y1", y5(r.update)).attr("y2", y5(r.update)).attr("opacity", 1);
      setPanel({ edge: s.edge, counter: `${s.plays} plays · game ${s.play.game}`, comb: "all", rows: s.p, showUpd: true, hull: s.hull }, dur);
      return;
    }
    if (name === "games" || name === "parity") {
      const gi = name === "parity" ? G.length - 1 : Math.min(G.length - 1, Math.floor(prog * G.length));
      drawGames(gi); parG.transition().duration(DUR).attr("opacity", name === "parity" ? 1 : 0);
      const s = name === "parity" && pIdx > 0 ? G[pIdx] : G[gi];
      setPanel({ edge: s.edge, counter: gameCounter(s), comb: "all", rows: s.p, showUpd: true, hull: s.hull }, dur);
      return;
    }
    if (name === "gameHull") {
      const gi = Math.min(G.length - 2, Math.floor(prog * (G.length - 1)));
      const s = G[gi]; ghHull.transition().duration(dur).attr("d", hullPath(s.hull));
      ghDots.selectAll("circle").data(s.disp.fwd.map((f, k) => [f, s.disp.lat[k], s.disp.inside[k]])).join("circle")
        .attr("cx", d => hx(-d[1])).attr("cy", d => hy(d[0])).attr("r", 3.2).attr("fill", d => d[2] ? C.blue : C.magenta).attr("fill-opacity", 0.75);
      ghLab.text(`envelope after game ${s.g}, moves from game ${s.g + 1} (${glab(s.g + 1)})`);
      ghCov.text(s.inside_share == null ? "" : `${Math.round(s.inside_share * 100)}% inside`);
      setPanel({ edge: s.edge, counter: gameCounter(s), comb: "all", rows: s.p, showUpd: true, hull: s.hull }, dur);
      return;
    }
    // static steps
    const fin = G[G.length - 1];
    const pre = { comb: "all", rows: priorRows, edge: P.roster_edge, counter: "before snap 1" }, pre0 = Object.assign({ hull: P.hull0 }, pre);
    const st = {
      field40: { comb: null }, drills: { comb: null }, morph: { comb: null }, accelLine: { comb: "A5" }, allLines: { comb: "all" },
      train: { comb: "all" }, model: { comb: "all" }, shrink: { comb: "all" }, prior: pre, class2025: pre,
      phys1: pre, phys2: pre, phys3: pre, phys4: pre, phys5: pre, phys6: pre, phys7: pre, calib1: pre, calib2: pre,
      calib3: pre0, noise: pre0, blend: pre0,
      season: { comb: "all", rows: fin.p, edge: fin.edge, counter: gameCounter(fin), showUpd: true, hull: fin.hull },
      all1: { comb: "all", rows: fin.p, edge: fin.edge, counter: gameCounter(fin), showUpd: true, hull: fin.hull },
      all2: { comb: "all", rows: fin.p, edge: fin.edge, counter: gameCounter(fin), showUpd: true, hull: fin.hull },
      all3: { comb: "all", rows: fin.p, edge: fin.edge, counter: gameCounter(fin), showUpd: true, hull: fin.hull } }[name]
      || (["ribbon", "reach", "reachCmp"].includes(name) ? { comb: "all", rows: fin.p, edge: fin.edge, counter: gameCounter(fin), showUpd: true, hull: fin.hull } : {});
    setPanel(Object.assign({ edge: P.roster_edge, counter: "" }, st), DUR);
  };
  const node = root.node();
  node.update = update;
  update(0);
  return node;
}
