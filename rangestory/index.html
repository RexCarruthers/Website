Reading a player’s range session

I was checking the Masters Leaderboard and noticed they had a live feed of the practice range with Trackman data for the 4 rounds as well as the 3 days of practice rounds/nonsense beforehand. One issue with actual course golf data is that you only observe a maximum of one shot per player per round from any given position and it is hard to tell exactly where they are aiming and what the intent of the shot is. With some players hitting up to 250 shots on the range per day I hypothesised that they would be hitting multiple balls at their stock yardages at the same target and I would be able to measure the dispersion, compare players and potentially use for course management tools down the road.

Scraping the data from the Masters website was relatively straightforward using the R package httr and jsonlite with all of the data in json format available from an open api call.

Pick a player above and scroll.

Each line is one shot from the selected player, viewed from above. The player aims roughly up the page from various bays during their time at the tournament. The range at Augusta is large enough that even the longest players can hit their driver down two different fairways and also includes 3 greens to aim for. All this to say - they aren’t just hitting it straight, even in the same practice session, and we will have to account for that.

To simplify the analysis we will just be looking at the carry distance/location of each shot and ignore shot shape/spin. So we collapse each shot down to a single point: its landing position and translate all the shots to be hit from position (0,0). We are also assuming the wind conditions are the same for each shot grouping and ignoring them for today.

These dots aren’t all from one go. A player splits their range time across multiple sessions and bays — different days, different warm-ups, different intent. Each colour is one session.

Within each session I used the clustering algorithm DBSCAN because it excels at selected dense groups and filtering out noise. I increased the epsilon value (the maximum distance between two points for them to be considered in the same group) by the distance of the shot as it makes practical sense that dispersion will increase with distance. Each colour now is a cluster of shots aimed at one target. The grey points are noise.

I’ve dropped the points that can’t be attributed to any group. Also note that there are more groups than colours so this is slightly misleading.

Now the real trick. Each cluster is aimed at a different target, so comparing them directly is meaningless. We rotate every cluster so its centre lies on the same vertical line — straight up the page. Now every shot’s lateral deviation is measured against its own estimated intended target.

With every shot referenced to a common axis, we can ask: how big is this player’s overall dispersion? One answer is the convex hull, the smallest polygon containing all of their normalised landing points. I removed the outside 5% of shots to not too harshly punish one or two wayward shots and potential methodological biases.

From the hull we extract two summary numbers: its area and its length — the range of carry distances covered. Their ratio is an “average width” measured in yards: how far sideways the player tends to miss, per yard of carry. One number for an entire session.

Compute that number for every player in the field and plot it against their tournament finish. The relationship is positively correlated and statistically significant using Spearman and Kendall correlation tests. This was much more than I anticipated considering the skill level of the field, variability of golf results and only used lateral dispersion.

shotsViz = {
  const width = 600, height = 600;
  const svg = d3.create("svg")
    .attr("width", width)
    .attr("height", height)
    .attr("viewBox", `0 0 ${width} ${height}`)
    .style("max-width", "100%")
    .style("height", "auto")
    .style("background", "#ffffff");

  // Reference axes
  svg.append("line").attr("class", "ref-line")
    .attr("x1", xScale(-80)).attr("x2", xScale(80))
    .attr("y1", yScale(0)).attr("y2", yScale(0))
    .attr("stroke", "#ddd").attr("stroke-dasharray", "3,3");
  svg.append("line").attr("class", "ref-line")
    .attr("x1", xScale(0)).attr("x2", xScale(0))
    .attr("y1", yScale(-20)).attr("y2", yScale(360))
    .attr("stroke", "#ddd").attr("stroke-dasharray", "3,3");

  // Tee
  svg.append("circle").attr("class", "tee")
    .attr("cx", xScale(0)).attr("cy", yScale(0))
    .attr("r", 4).attr("fill", "black");

  const lineGen = d3.line().x(d => xScale(d[0])).y(d => yScale(d[1]));

  // Trajectories
  svg.append("g").attr("class", "trajectories")
    .selectAll("path")
    .data(playerData.shots.filter(d => d.traj))
    .join("path")
      .attr("class", "trajectory")
      .attr("d", d => lineGen(d.traj))
      .attr("fill", "none")
      .attr("stroke", "steelblue")
      .attr("stroke-width", 1)
      .attr("opacity", 0.4);

  // Shot circles
  svg.append("g").attr("class", "shots")
    .selectAll("circle")
    .data(playerData.shots)
    .join("circle")
      .attr("class", "shot")
      .attr("cx", d => xScale(d.land_x))
      .attr("cy", d => yScale(d.land_z))
      .attr("r", 3)
      .attr("fill", "steelblue")
      .attr("opacity", 0);

  // Hull + annotations
  if (playerData.hull && playerData.hull.length > 2) {
    svg.append("path").attr("class", "hull")
      .attr("d", lineGen(playerData.hull) + "Z")
      .attr("fill", "steelblue")
      .attr("fill-opacity", 0)
      .attr("stroke", "steelblue")
      .attr("stroke-opacity", 0)
      .attr("stroke-width", 1.5);

    // Geometry for annotations
    const cx    = d3.mean(playerData.hull, d => d[0]);
    const cz    = d3.mean(playerData.hull, d => d[1]);
    const minZ  = d3.min(playerData.hull,  d => d[1]);
    const maxZ  = d3.max(playerData.hull,  d => d[1]);
    const maxX  = d3.max(playerData.hull,  d => d[0]);

    // Area label inside hull
    svg.append("text").attr("class", "anno area-label")
      .attr("x", xScale(cx)).attr("y", yScale(cz))
      .attr("text-anchor", "middle")
      .attr("dominant-baseline", "central")
      .attr("font-size", 13).attr("font-weight", "bold")
      .attr("fill", "#1a4a7a").attr("opacity", 0)
      .text(`Area = ${playerData.hull_area} yd²`);

    // Length bracket on right side of hull
    const bx = xScale(maxX) + 14;
    const tickW = 6;
    const lengthGroup = svg.append("g").attr("class", "anno length-group").attr("opacity", 0);
    lengthGroup.append("line")
      .attr("x1", bx).attr("x2", bx)
      .attr("y1", yScale(minZ)).attr("y2", yScale(maxZ))
      .attr("stroke", "#1a4a7a").attr("stroke-width", 1.5);
    lengthGroup.append("line")
      .attr("x1", bx - tickW).attr("x2", bx + tickW)
      .attr("y1", yScale(minZ)).attr("y2", yScale(minZ))
      .attr("stroke", "#1a4a7a").attr("stroke-width", 1.5);
    lengthGroup.append("line")
      .attr("x1", bx - tickW).attr("x2", bx + tickW)
      .attr("y1", yScale(maxZ)).attr("y2", yScale(maxZ))
      .attr("stroke", "#1a4a7a").attr("stroke-width", 1.5);
    lengthGroup.append("text")
      .attr("x", bx + 10).attr("y", yScale((minZ + maxZ) / 2))
      .attr("text-anchor", "start")
      .attr("dominant-baseline", "central")
      .attr("font-size", 13).attr("font-weight", "bold")
      .attr("fill", "#1a4a7a")
      .text(`Length = ${playerData.hull_length} yd`);
  }

  // Big metric text — split into label and value so they can morph independently
  // into the scatter's y-axis label and the player's dot respectively.
  // Position via transform so the morph animates cleanly (translate + rotate
  // interpolate component-wise).
  svg.append("text").attr("class", "metric-label")
    .attr("transform", "translate(200, 565) rotate(0)")
    .attr("text-anchor", "end")
    .attr("font-size", 22).attr("font-weight", "bold")
    .attr("fill", "#1a4a7a").attr("opacity", 0)
    .text("Dispersion metric");

  svg.append("text").attr("class", "metric-value")
    .attr("transform", "translate(210, 565)")
    .attr("text-anchor", "start")
    .attr("font-size", 22).attr("font-weight", "bold")
    .attr("fill", "steelblue").attr("opacity", 0)
    .text(`= ${playerData.dispersion_metric}`);

  // Morph dot — invisible until the scatter transition, then it appears
  // at the value's location and translates to the scatter point.
  svg.append("circle").attr("class", "morph-dot")
    .attr("cx", 210).attr("cy", 558)
    .attr("r", 7)
    .attr("fill", "steelblue")
    .attr("stroke", "white").attr("stroke-width", 2)
    .attr("opacity", 0);

  // ---- Scatter group (stage 8) ----
  const maxRank   = d3.max(allPlayers, d => d.rank);
  const maxMetric = d3.max(allPlayers, d => d.dispersion_metric) * 1.1;
  const rankScale   = d3.scaleLinear().domain([0, maxRank * 1.05]).range([80, 540]);
  const metricScale = d3.scaleLinear().domain([0, maxMetric]).range([520, 80]);

  const scatter = svg.append("g").attr("class", "scatter").attr("opacity", 0);

  // Axes
  scatter.append("g")
    .attr("transform", `translate(0, ${metricScale(0)})`)
    .call(d3.axisBottom(rankScale).ticks(6))
    .selectAll("text").attr("font-size", 11);
  scatter.append("g")
    .attr("transform", `translate(${rankScale(0)}, 0)`)
    .call(d3.axisLeft(metricScale).ticks(6))
    .selectAll("text").attr("font-size", 11);

  // X-axis label only — y-axis label is supplied by the morphing .metric-label
  scatter.append("text")
    .attr("x", (rankScale(0) + rankScale(maxRank)) / 2).attr("y", 565)
    .attr("text-anchor", "middle").attr("font-size", 12)
    .text("Tournament rank →");

  // Regression line (clipped to plot area)
  const slope     = correlation.linear_slope;
  const intercept = correlation.linear_intercept;
  const yAt = r => intercept + slope * r;
  scatter.append("line").attr("class", "regression")
    .attr("x1", rankScale(0))
    .attr("y1", metricScale(yAt(0)))
    .attr("x2", rankScale(maxRank))
    .attr("y2", metricScale(yAt(maxRank)))
    .attr("stroke", "#e74c3c").attr("stroke-width", 2)
    .attr("stroke-dasharray", "5,3").attr("opacity", 0.8);

  // All-player dots — selected player is rendered as a normal grey dot here;
  // the morph dot is what visually represents the selected player.
  scatter.selectAll("circle.player-dot")
    .data(allPlayers)
    .join("circle")
      .attr("class", "player-dot")
      .attr("cx", d => rankScale(d.rank))
      .attr("cy", d => metricScale(d.dispersion_metric))
      .attr("r",  3)
      .attr("fill", "#bbb")
      .attr("opacity", 0.6)
      .style("cursor", "pointer")
      .append("title")
        .text(d => `${d.name}\nRank: ${d.rank}\nDispersion: ${d.dispersion_metric}`);

  // Compute the morph targets for the selected player and stash them on the
  // SVG node so the animate cell can read them.
  const sel = allPlayers.find(d => d.name === selectedPlayer);
  const node = svg.node();
  node.__morphTargets = sel ? {
    dotX: rankScale(sel.rank),
    dotY: metricScale(sel.dispersion_metric),
    // Y-axis label position (rotated -90, centered along left side of plot)
    labelX: -300,    // because rotate(-90) is in effect
    labelY: 30,
    valueX: rankScale(sel.rank),
    valueY: metricScale(sel.dispersion_metric) - 16
  } : null;

  // Selected player name label (shown alongside the morph dot once docked)
  scatter.append("text").attr("class", "selected-name")
    .attr("x", sel ? rankScale(sel.rank) : 0)
    .attr("y", sel ? metricScale(sel.dispersion_metric) - 14 : 0)
    .attr("text-anchor", "middle")
    .attr("font-size", 12).attr("font-weight", "bold")
    .attr("fill", "steelblue")
    .attr("opacity", 0)
    .text(selectedPlayer);

  // Correlation labels (top-right)
  scatter.append("text")
    .attr("x", 530).attr("y", 100).attr("text-anchor", "end")
    .attr("font-size", 11).attr("fill", "#444")
    .text(`Spearman ρ = ${correlation.spearman}`);
  scatter.append("text")
    .attr("x", 530).attr("y", 116).attr("text-anchor", "end")
    .attr("font-size", 11).attr("fill", "#444")
    .text(`Kendall τ = ${correlation.kendall}`);

  return svg.node();
}
animate = {
  const stage = crTriggerIndex;
  const sel   = d3.select(shotsViz);
  const dur   = 700;

  // Reference axes & tee — fade out for scatter view
  sel.selectAll(".ref-line, .tee")
    .transition("refs").duration(dur)
    .attr("opacity", stage >= 8 ? 0 : 1);

  // Trajectories
  sel.selectAll(".trajectory")
    .transition("traj").duration(dur)
    .attr("opacity", stage === 0 ? 0.4 : 0);

  // Shot positions
  sel.selectAll(".shot")
    .transition("pos").duration(dur)
    .attr("cx", d => xScale(stage >= 5 && d.norm_x != null ? d.norm_x : d.land_x))
    .attr("cy", d => yScale(stage >= 5 && d.norm_z != null ? d.norm_z : d.land_z));

  // Shot opacity & colour
  sel.selectAll(".shot")
    .transition("style").duration(dur)
    .attr("opacity", d => {
      if (stage === 0) return 0;
      if (stage >= 8) return 0;
      if (stage >= 4 && d.cluster === 0) return 0;
      if (stage === 3) return d.cluster === 0 ? 0.25 : 0.7;
      return 0.7;
    })
    .attr("fill", d => {
      if (stage === 2) return sessionColor(d.sess);
      if (stage >= 3) return clusterColor(d.cluster);
      return "steelblue";
    });

  // Hull
  sel.select(".hull")
    .transition("hull").duration(dur)
    .attr("fill-opacity",  (stage === 6 || stage === 7) ? 0.2 : 0)
    .attr("stroke-opacity",(stage === 6 || stage === 7) ? 1   : 0);

  // Annotations: staggered reveal at stage 7 — area first, then length,
  // then metric label and value together.
  const showAnno = stage === 7;
  sel.select(".area-label")
    .transition("anno-area").duration(dur)
    .attr("opacity", showAnno ? 1 : 0);
  sel.select(".length-group")
    .transition("anno-len").duration(dur)
    .delay(showAnno ? 250 : 0)
    .attr("opacity", showAnno ? 1 : 0);

  // Metric label + value: appear at stage 7 in their hull-caption position;
  // at stage 8 they morph — label rotates and slides to the y-axis,
  // value moves to the player's scatter point and shrinks to the dot size.
  const targets = shotsViz.__morphTargets;

  if (stage === 7) {
    sel.select(".metric-label")
      .transition("morph-label").duration(dur).delay(500)
      .attr("opacity", 1)
      .attr("transform", "translate(200, 565) rotate(0)")
      .attr("text-anchor", "end")
      .attr("font-size", 22);
    sel.select(".metric-value")
      .transition("morph-value").duration(dur).delay(500)
      .attr("opacity", 1)
      .attr("transform", "translate(210, 565)")
      .attr("font-size", 22)
      .attr("fill", "steelblue");
    sel.select(".morph-dot")
      .transition("morph-dot").duration(dur)
      .attr("opacity", 0);
    sel.select(".selected-name")
      .transition("name").duration(dur)
      .attr("opacity", 0);
  } else if (stage === 8 && targets) {
    // Label morphs to the y-axis position (centered along the left of the plot)
    sel.select(".metric-label")
      .transition("morph-label").duration(900)
      .attr("opacity", 1)
      .attr("transform", "translate(30, 300) rotate(-90)")
      .attr("text-anchor", "middle")
      .attr("font-size", 12);
    // Value text fades out as the dot takes over
    sel.select(".metric-value")
      .transition("morph-value").duration(400)
      .attr("opacity", 0);
    // Morph dot appears at the value's position, then translates to the scatter point
    sel.select(".morph-dot")
      .transition("morph-dot-fade").duration(200)
      .attr("opacity", 1)
      .transition("morph-dot-move").duration(700)
      .attr("cx", targets.dotX)
      .attr("cy", targets.dotY);
    // Selected player name appears after the dot has docked
    sel.select(".selected-name")
      .transition("name").duration(400).delay(700)
      .attr("opacity", 1);
  } else {
    // All other stages: hide everything
    sel.select(".metric-label")
      .transition("morph-label").duration(dur)
      .attr("opacity", 0);
    sel.select(".metric-value")
      .transition("morph-value").duration(dur)
      .attr("opacity", 0);
    sel.select(".morph-dot")
      .transition("morph-dot").duration(dur)
      .attr("opacity", 0);
    sel.select(".selected-name")
      .transition("name").duration(dur)
      .attr("opacity", 0);
  }

  // Scatter (axes, regression line, all-player dots)
  sel.select(".scatter")
    .transition("scatter").duration(dur)
    .attr("opacity", stage === 8 ? 1 : 0);

  return stage;
}

Wrap Up

This method makes a lot of assumptions and simplifications and obviously isn’t foolproof, I’ve listed a few of them below. Charl Schwarzel and Fred Couples have broken it on either end by not hitting enough long shots to cluster and just having the time of his life on the range respectively (go back to the top and select them to see). Players and their teams would have simulation Trackman data to understand their shot dispersion going into a tournament but I believe I’ve created a decent proxy for the outsiders. The next steps are to extend this to distance dispersion, create player 2D dispersion models and then utilise them on course to quantify how good shots actually were and create course management/planning tools.

Limitations/Notes

  • The choice to use convex hull for the dispersion metric penalises bad shots and doesn’t reward good shots. Unless you are hitting a longer or shorter shot than you have previously more shots can only make it worse

  • Taking cluster centres as the intended target doesn’t take into account shot bias that would effect the whole cluster. For example, I can pretty consistently hit a weak slice to the right which would be a tightish cluster but nowhere near my intended target.

  • The fact that the golfers playing in the Masters are professional with very tight shot dispersions and aren’t trying to optimise for my dispersion metric does alleviate both of these. It also still managed to differentiate between players that made the cut and those that didn’t. Even though those that did had at least 2 more range warm ups to worsen their dispersion metric.
