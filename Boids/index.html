AFL Tracking Data

While using AFL tracking data to create a GIF similar to the one below for a uni assignment I was struck by how much the movement reminded me of a biological organism. By chance I stumbled on this video coding a flocking simulation using “boids” and wondered if the same process could be used to create similar movement to AFL. But first, what are boids?

hull_summary <- tracking %>%
  filter(onBench == 0) %>%
  group_by(squad_name, period_secs) %>%
  summarise(
    centroid_x = mean(x),
    centroid_y = mean(y),
    hull = list({
      i <- chull(x, y)
      tibble(x = x[i], y = y[i])

    .groups = "drop"

Boids

Boids (short for “bird-objects”) is a model introduced by Craig Reynolds in 1986 to simulate coordinated group movement, like bird flocks or schools of fish. Each agent boid follows simple local rules based on nearby neighbours. At each timestep, its velocity is updated by combining the effects of these rules, producing emergent, lifelike group behaviour from very simple interactions.

The proximity of its neighbours is generally defined using the below diagram which, interestingly, often seen in sports analytics papers when describing pressure.

The three steering behaviours are below with the red arrow showing the update to the current velocity based on that rule:

Separation (S) - Steer to avoid crowding local flockmates

Alignment (A) - Steer towards the average heading of local flockmates

Cohesion (C) - steer to move toward the average position of local flockmates
